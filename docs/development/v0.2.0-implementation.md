## 未完成与风险

Query Builder 是有限模板/关键词，不是通用自然语言翻译器；复杂或语义冲突规则仍由模型判断并允许 review。低热度不等于低相关，分数也不等于事实可靠性。全局 source + external_id 唯一仍限制一个 Item 归一个 Topic，未扩张成多 Topic 关系。

8B 模型仍会误判、失败或幻觉；JSON / 语言 / 注入 / 年份 / 来源检查不能证明完整事实正确。上下文 24576 与 Analyze 8192 输出预算可能增加 RAM/VRAM 和延迟；Digest 4096/8192、最多一次 retry、每次 180 秒。规则过长明确报错，不无声裁掉规则。时效随钟表变化不会自动更新指纹，需主动复核。

没有新来源、视频下载/字幕/全文、Embedding、Vector DB、RAG、登录/多用户、云部署、持久化队列、跨进程锁、分页或新 AI 框架。真实 Windows 通知没有在本轮再次主动弹出；Fake 通知与 Scheduler 全套回归通过。本轮可作为 v0.2.0 本地候选继续试用，尚不宣称长期无人值守的语义质量达到保证。
